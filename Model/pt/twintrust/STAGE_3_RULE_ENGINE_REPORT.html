4. Stateful Stall Confirmation Design

To avoid false alarms during fan spin-up or transient dips, the Rule Engine requires consecutive readings below stall threshold:

Reading 1: fan=ON, RPM=10.0  -> Counter=1 (Stall pending, no alarm)
Reading 2: fan=ON, RPM=12.0  -> Counter=2 (Stall pending, no alarm)
Reading 3: fan=ON, RPM=8.0   -> Counter=3 >= 3 -> [CRITICAL] FAN_STALL CONFIRMED!
Recovery : fan=ON, RPM=1450  -> Counter reset to 0

State is isolated per device_id, preventing cross-plant interference.
